The outline of the repo is as given below:

The learnings throughout the project so far are:
- Image loading and environment setup
- Image preprocessing using Pillow
- Text extraction from images using EasyOCR
- Confidence-based filtering of OCR output
- Sentiment analysis using TextBlob
